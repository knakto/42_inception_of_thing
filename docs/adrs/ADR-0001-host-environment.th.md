# ADR-0001: เลือกใช้ Host Environment ภายใต้สิทธิ์ของผู้ใช้

- **Status:** Approved

## Context

ข้อกำหนดของโปรเจกต์ระบุให้ดำเนินงานภายใน Virtual Machine อย่างไรก็ตาม สภาพแวดล้อมที่มีอยู่มีทรัพยากรจำกัด จึงพิจารณาทางเลือก 3 แนวทาง:

1. สร้างและใช้งาน Virtual Machine ตามข้อกำหนดของโปรเจกต์
2. ติดตั้งและเรียกใช้เครื่องมือบน Host เท่าที่สิทธิ์ของผู้ใช้อนุญาต โดยไม่พึ่งพาสิทธิ์ `root` หรือ `sudo`
3. ใช้ Cloud Environment เพื่อให้สามารถจัดการระบบด้วยสิทธิ์ระดับผู้ดูแลได้

## Decision

เลือกดำเนินงานบน Host ภายใต้สิทธิ์ของผู้ใช้ที่มีอยู่ และเลือกติดตั้งเครื่องมือภายนอกในรูปแบบ standalone single-binary เท่าที่รองรับ เพื่อลดการพึ่งพาการติดตั้งระดับระบบและสิทธิ์ผู้ดูแล

## Justification

- ลดความหน่วงจากการทำงานผ่าน Virtual Machine
- ใช้ทรัพยากรของเครื่องเท่าที่จำเป็น
- เริ่มทดลองและพัฒนาได้ทันที โดยไม่ต้องเตรียม Cloud Environment เพิ่มเติม

## Consequences

### Pros

- เริ่มทดลองและลงมือพัฒนาได้ทันที
- ลดความหน่วงจากการทำงานผ่าน Virtual Machine
- สภาพแวดล้อมและขั้นตอนเริ่มต้นเข้าใจได้ง่ายขึ้น

### Cons

- ภายใต้ข้อจำกัดด้านสิทธิ์ปัจจุบัน อาจไม่สามารถใช้งาน K3d ได้ เนื่องจากต้องพึ่งพา Docker หรือ container runtime ที่ต้องมีสิทธิ์ใช้งานเพียงพอ
- ต้องค้นหาและจัดเตรียม dependencies ที่จำเป็นให้ทำงานได้ภายใต้สิทธิ์ของผู้ใช้ โดยเลือกใช้ standalone single-binary เมื่อมีให้ใช้งาน
- การใช้ Host แทน Virtual Machine อาจไม่สอดคล้องกับข้อกำหนดของโปรเจกต์ และควรพิจารณาผลกระทบต่อการประเมินงาน
